# 스알

**내 주식 동료, 스알!**

## 개요

스알은 주식 종목을 여러 각도에서 들여다보는 데스크톱 앱입니다.

## 설치 및 실행 방법

[Releases](../../releases/latest)에서 운영체제에 맞는 파일을 내려받습니다.

| 운영체제 | 파일 |
| --- | --- |
| macOS | `StockAnalysis-<버전>-mac-arm64.dmg` (애플 실리콘) |
| Windows | `StockAnalysis-<버전>-win-x64.exe` |

**macOS**  
dmg를 열고 앱을 Applications 폴더로 끌어 넣습니다.  
서명 인증서가 없는 앱이라 처음 열 때 경고가 뜹니다 ㅜㅜ.

**Windows**  
exe를 실행하여 설치할 수 있습니다.

## 주요 기능

**대화로 분석하기**   
스알에서는 대화를 통해서 주식을 자세하게 분석할 수 있습니다.  
챗에서 부를 수 있는 도구는 아래와 같으며, 스알이 자동으로 사용자의 대화를 이해해 도구를 호출합니다.

**도구**  

| 도구 | 내용 |
| --- | --- |
| 가격 구간 | 지지·저항 박스와 최근 흐름 |
| 파동 분석 | 고점과 저점을 이은 파동 구조 |
| 볼린저 분석 | 밴드 폭과 이탈 구간 |
| 밸류에이션 | 실적 기반 적정 주가 범위 |
| 투자 판정 | 점수제로 계산한 매수·매도 의견 |
| 투자 시나리오 | 조건별로 갈리는 앞으로의 경우의 수 |
| 공시 | 최근 공시 목록과 본문 |
| 뉴스 | 종목 관련 기사 |
| 증권사 리포트 | 애널리스트 목표가와 의견 |
| 시장 지수 | 코스피·코스닥과 해외 지수 |
| 거시 지표 | 환율, 금리, 원자재 |
| 시장 브리핑 | 오늘 시장 요약 |
| 쉽게 말하면 | 앞의 결과를 말로 풀어 쓴 요약 |
| 즐겨찾기 보드 | 담아 둔 종목의 현재가와 등락 |

## 업데이트

자동으로 업데이틀 확인합니다.   
또한 설정 화면의 앱 버전 카드에서 "업데이트 확인"을 누르면 새 버전이 있는지 알 수 있습니다.
