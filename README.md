# 스알

내 주식 동료, 스알

> 현행 기준: 2026-09-07 · v0.53.0 · closed-beta-test 중입니다.

## 개요

스알은 종목 하나를 여러 각도에서 들여다보는 데스크톱 앱입니다.
가격과 재무, 공시와 뉴스를 한 화면에 모아 놓고 봅니다.
같은 자료를 놓고 챗으로 물어보면 앱이 분석 도구를 직접 불러 답합니다.
국내 종목과 미국 종목을 모두 다룹니다.
데이터 제공처의 키는 쓰는 사람 컴퓨터에만 저장되고 밖으로 나가지 않습니다.

이 저장소는 설치 파일을 나눠 주는 곳입니다. 소스 코드는 올라오지 않습니다.

## 설치 및 실행 방법

[Releases](../../releases/latest)에서 운영체제에 맞는 파일을 내려받습니다.

| 운영체제 | 파일 |
| --- | --- |
| macOS | `StockAnalysis-<버전>-mac-arm64.dmg` (애플 실리콘), `-mac-x64.dmg` (인텔) |
| Windows | `StockAnalysis-<버전>-win-x64.exe` |

**macOS**
dmg를 열고 앱을 Applications 폴더로 끌어 넣습니다.
서명 인증서가 없는 앱이라 처음 열 때 경고가 뜹니다.
앱 아이콘을 마우스 오른쪽 버튼으로 누르고 "열기"를 고르면 실행됩니다.

**Windows**
exe를 실행하면 설치 마법사가 뜹니다. 설치 위치를 고를 수 있습니다.

앱을 처음 켜면 설정 화면에서 쓰려는 데이터 제공처의 키를 넣습니다.

## 주요 기능

**대화로 분석하기**
종목 이름을 넣고 물어보면 앱이 필요한 분석 도구를 골라 부릅니다.
챗에서 부를 수 있는 도구는 17가지입니다.
답변에는 화면에서 직접 실행했을 때와 같은 결과 카드가 붙습니다.

**한 종목을 14가지 관점으로**
분석 화면에서 원하는 항목만 골라 실행합니다.

| 항목 | 무엇을 보나 |
| --- | --- |
| 가격 구간 | 지지·저항 박스와 최근 흐름 |
| 파동 분석 | 고점과 저점을 이은 파동 구조 |
| 볼린저 분석 | 밴드 폭과 이탈 구간 |
| 밸류에이션 | 실적 기반 적정 주가 범위 |
| 투자 판정 | 점수제로 계산한 매수·매도 의견 |
| 투자 시나리오 | 조건별로 갈리는 앞으로의 경우의 수 |
| 공시 | 최근 공시 목록과 본문 |
| 뉴스 | 종목 관련 기사 |
| 증권사 리포트 | 애널리스트 목표가와 의견 |
| 시장 지수 | 코스피·코스닥과 해외 지수 |
| 거시 지표 | 환율, 금리, 원자재 |
| 시장 브리핑 | 오늘 시장 요약 |
| 쉽게 말하면 | 앞의 결과를 말로 풀어 쓴 요약 |
| 즐겨찾기 보드 | 담아 둔 종목의 현재가와 등락 |

**투자 판정은 한 곳에서만**
매수·매도 결론은 투자 판정 항목만 냅니다.
점수를 정해진 방식으로 계산하고 판단 근거와 주의 문구를 함께 보여 줍니다.
나머지 항목은 조건과 확인할 점까지만 적습니다.

## 업데이트

설정 화면의 앱 버전 카드에서 "업데이트 확인"을 누르면 새 버전이 있는지 알려 줍니다.
앱을 켤 때도 한 번 확인하고, 새 버전이 있으면 오른쪽 아래에 알림이 뜹니다.
"업데이트"를 누르면 설치 파일을 내려받아 열고 앱을 끕니다.
설치가 끝나면 앱을 다시 켜면 됩니다.
